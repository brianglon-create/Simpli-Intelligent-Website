# Project Status

## What this is

V1 public parent-company landing page for **Simpli Intelligent**.

Primary goals:

1. Establish a credible public company presence for Google Workspace, startup programs, partners, and future customers.
2. Explain the parent brand and initial product family.
3. Stay simple, fast, and expandable without requiring a rebuild.

## What this is not

- Not Simpli Operate
- Not Simpli Reach
- Not a product application
- Not a CMS-driven marketing site
- Not an authenticated experience
- Not connected to Supabase or any database

## Current scope (V1)

- One-page Next.js site
- Header, hero, mission, products, intelligence layer overview, founder message (About), contact, footer
- Final approved hero copy: **Built for Small Business. Built by Small Business.**
- Finalized founder section: **Why We Built Simpli**
- SEO metadata, sitemap, robots.txt
- Configurable contact email (`mailto:`)
- Automated tests for page content and major interactions

## Explicitly out of scope for this sprint

- Analytics
- Cookie banners
- Contact forms requiring a backend
- Login / pricing / newsletter capture
- Custom domain connection
- Automatic production deploy
- Public product application URLs
- Logos beyond text wordmark / SI monogram
